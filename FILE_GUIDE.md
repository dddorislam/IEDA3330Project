# ETF experiment file guide

The ZIP contains the code, frozen Yahoo Finance price snapshots, and saved results for the SPY, QQQ, and IWM volatility and return experiments. The horizons are 5 and 22 trading sessions. Files with the same purpose are grouped by filename pattern below. In patterns, `*` stands for a fund, horizon, random seed, or another varying part of the path.

## Where to start

Open `README.md` for installation and run commands. The four commands under “Check the tables using the archived forecasts” replay the reported comparisons using the included files. Refit the models with `reproduce.py` in a separate fresh extraction, then run the return and portfolio scripts in the order listed in the README. Trained model weights are generated by the refit. The ZIP includes the original forecasts, selection records, and timing measurements for comparison.

For individual volatility forecasts, open `runs/main_20261118/forecast_ledger.csv`. For expected-return results, open `runs/return_comparison/forecast_summary.csv`. For the portfolio results, start with `runs/return_comparison/strategy_summary.csv` and use `daily_strategies.csv` to trace them to individual holding days.

## Code and configuration

| File | What it does |
|---|---|
| `reproduce.py` | Runs the pilot in its own folder, then validates, locks, fits, and verifies the main volatility experiment. It runs the volatility report and interval-figure builders afterward. |
| `download_data.py` | Downloads missing historical Yahoo Finance inputs and audits archived prices for coverage, duplicates, price consistency, and corporate actions. |
| `get_confirmation_data.py` | Fetches the 2026 extension, checks exchange sessions, aligns adjusted-close levels at 31 December 2025, and writes the joined snapshots with their checksums. |
| `run_experiment.py` | Prepares daily predictors and future variance targets, defines chronological splits, and fits the pilot LSTMs and statistical baselines. The main and return scripts also reuse its data-preparation functions. |
| `evaluate.py` | Scores saved pilot forecasts, aggregates fund-level results, and estimates paired uncertainty by resampling blocks of dates. |
| `verify_results.py` | Independently checks pilot target dates, training-only scaling, saved model predictions, and the GARCH baseline calculation. |
| `predict.py` | Uses pilot model checkpoints generated by training to make a volatility forecast at a specified historical date. It averages the seed-specific variance forecasts. |
| `main_experiment.py` | Fits the direct volatility LSTM candidates, plain HAR, constant and linear corrections, and the HAR–LSTM correction. Runs validation, records model choices, and scores the earlier and reserved periods. |
| `verify_main.py` | Checks the main fitted models and forecast rows and exports the common-date volatility forecast ledger and fund-level scores. |
| `check_report_results.py` | Recomputes observed variance from archived prices, verifies headline QLIKE comparisons, and exports exact evaluation cutoffs. |
| `compare_returns.py` | Fits five- and 22-session signed-return models and runs the portfolio backtest. The `--policies-only` flag replays portfolio results using saved volatility forecasts. |
| `summarize_returns.py` | Computes forecast averages, MAE, RMSE, and return skill. It also computes paired portfolio-return intervals against plain HAR and fixed weights. |
| `link_risk_return.py` | Matches risk and return forecasts on fund, forecast date, horizon, and outcome date. Computes risk-group averages and within-fund rank correlations. |
| `build_report.py` | Builds the earlier pilot-era PDF and Markdown results report from its saved experiment outputs and figures. |
| `write_main_report.py` | Calculates the main volatility comparisons and generates their LaTeX report and interval data from fitted-model results. |
| `plot_main_intervals.py` | Draws the plot of paired QLIKE differences for the exploratory and reserved volatility periods. |
| `runs/pilot-20261118-184624-535/prefit_grid.py` | Optional helper that precomputes pilot validation-grid training jobs in parallel. |
| `runs/pilot-20261118-184624-535/prefit_selected.py` | Optional helper that precomputes fits for the selected pilot configurations. |
| `config.json` | Stores funds, horizons, historical date ranges, validation blocks, seeds, and pilot training settings. |
| `environment.json` | Records the Python, package, and platform details from the archived experiment environment. |
| `requirements-lock.txt` | Lists pinned Python dependencies for the experiment and reporting scripts. |

## Price data and audit records

| File or pattern | What it contains |
|---|---|
| `data/raw/*.csv` | Each ticker's main CSV contains daily open, high, low, close, adjusted close, volume, and corporate-action fields from 2004–2025. CSVs with the suffix `_actions_audit` list dividend and split dates with adjusted-return checks. |
| `data/raw/*_metadata.json` | Yahoo Finance metadata for each historical ticker, including exchange and trading information. |
| `data/audit.csv` | Per-fund checks for date coverage, missing or duplicate sessions, and corporate actions. |
| `data/manifest.json` | Historical data source links, retrieval information, adjustment settings, and SHA-256 checksums. |
| `runs/main_20261118/holdout/data/raw/*.csv` | Extended daily snapshots. Each includes the earlier history and 214 added 2026 sessions for one fund. |
| `runs/main_20261118/holdout/data/manifest.json` | Added session count and SHA-256 checksum for each extended snapshot. |

## Volatility results

| File or pattern | What it contains |
|---|---|
| `runs/main_20261118/forecast_ledger.csv` | Forecast date, outcome date, horizon, fund, model, predicted variance, observed variance, and scoring fields. It covers both the 2024–2025 exploratory comparison and the reserved 2026 volatility comparison. |
| `runs/main_20261118/evaluation_cutoffs.csv` | Last eligible training origin and outcome, plus first and last scored origins and final outcome, by evaluation block, fund, and horizon. |
| `runs/main_20261118/paired_intervals.csv` | Candidate-minus-benchmark QLIKE differences and paired intervals under multiple resampling block lengths. |
| `runs/main_20261118/ranking_h*.csv` | Mean chronological validation QLIKE, fitted parameter counts, and inference timings for the candidates at each horizon. |
| `runs/main_20261118/scores_by_fund_and_seed.csv` | QLIKE, MAE, and RMSE broken down by fund, horizon, model, and seed or ensemble. |
| `runs/main_20261118/lock.json` | Selected direct and hybrid model settings, training durations, the lock time, and reserved evaluation dates. |
| `reference_results/main/*` | Preserved copies of the original forecast ledger, scores, rankings, lock record, and paired intervals. These remain as reference results when replay or refitting writes into the run directory. |
| `reference_results/pilot/h*/macro_metrics.csv` | Pilot accuracy metrics aggregated across the three funds at the specified horizon. |
| `reference_results/pilot/h*/selection.json` | Architecture and training choices recorded by the pilot at that horizon. |
| `reference_results/timing/explore/h*/*/1/*.json` | One record per horizon, fund, model, and seed. Each records training time in seconds, inference time in microseconds, parameter count, selected epoch, and fitted scaling information. |

## Return, risk-group, and portfolio results

| File or pattern | What it contains |
|---|---|
| `runs/return_comparison/*_5.csv` | Actual and model-predicted signed returns over the next five trading sessions, by forecast date for one ETF. |
| `runs/return_comparison/*_22.csv` | The corresponding actual and predicted signed returns over 22 trading sessions. |
| `runs/return_comparison/*_epochs.json` | Selected training durations for the compact and reference return LSTMs, by seed, fund, and horizon. |
| `runs/return_comparison/forecast_summary.csv` | Average predicted and realized return, forecast error, and skill relative to the historical-average forecast. |
| `runs/return_comparison/daily_strategies.csv` | Portfolio signal, entry and exit dates, net daily return, equity exposure, and turnover for each strategy. |
| `runs/return_comparison/fixed_weights.csv` | The SPY, QQQ, and IWM portfolio weights calibrated from 2024–2025 plain HAR sizing and held fixed in the 2026 comparison. |
| `runs/return_comparison/strategy_summary.csv` | Compounded net gain, annualized mean return, annualized volatility, and average equity exposure over 192 common holding days. |
| `runs/return_comparison/strategy_intervals.csv` | Paired annualized mean net-return differences and intervals relative to plain HAR sizing. |
| `runs/return_comparison/fixed_exposure_intervals.csv` | Paired annualized mean net-return differences and intervals relative to the fixed-weight strategy. |
| `report/risk_return/paired_forecasts.csv` | The matched risk and signed-return forecasts with actual outcomes for each ETF, date, and horizon. |
| `report/risk_return/risk_bands.csv` | Counts, predicted and realized volatility, mean return forecasts, subsequent signed returns, and reference LSTM return RMSE by predicted-risk group. |
| `report/risk_return/associations.csv` | Within-fund rank correlations between predicted risk and predicted or observed returns, averaged across funds. Includes the reported intervals for hybrid risk. |
| `report/risk_return/forecast_quality.csv` | Supplemental return forecasts, RMSE, and average forecast-return-to-predicted-risk ratios on the matched sample. |

Most forecast and portfolio return columns use decimals. A return of `0.02` is 2%. Variance is in squared decimal-return units. QLIKE is a loss score, and volatility MAE and RMSE in the report are annualized volatility percentage points. The return summary's MAE and RMSE are stored in decimal-return units and multiplied by 100 for the report's percentage points.
